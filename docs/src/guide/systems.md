# Systems

This page will document the system types and feedback modes supported by
`LyapunovStability.jl`.

## System types

- `SLIT`
- `SystemDelayed`
- `LTIDisturbance`
- `LTIDisturbanceDelayedInput`

## Feedback modes

- `SOF`: static output feedback
- `SSF`: static state feedback
- `OL`: open loop
